# 🧠 SmartDocs: Cross-File Logic Analyzer

A Streamlit-powered tool that uses LLMs to generate graph-aware documentation for codebases. It features deep Excel header scanning, cross-file logic skeletons, and automated sanity checks.

## 🚀 Quick Start

### 1. Prerequisites
Ensure you have Python 3.9+ installed.

### 2. Installation
Install the required dependencies using pip:
```bash
pip install -r requirements.txt

###4. Running the App
Launch the Streamlit interface:
streamlit run SmartDocs.py or click the start_docs.bat
